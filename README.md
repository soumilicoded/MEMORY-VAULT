SyncXyou — Memory Vault™

An AI-powered personal knowledge & physical-asset management system. A working single-file web prototype: file a memory or register a physical object, and Claude classifies, tags, and makes it searchable in plain language — no folders, no keyword matching.

Live in this file: syncxyou.html — open it directly in a browser, or deploy it (GitHub Pages, Vercel, Netlify) as a static site.

What it does


Memory Vault — write a note, decision, or experience in plain language. Claude classifies it into a category (Knowledge / Experience / Relationship / Decision / Learning) and generates tags automatically. Search the vault with natural questions like "why did I choose this branch" instead of keywords.
Real-Life Storage Tracker — register where a physical object lives as a location path (e.g. Home > Bedroom > Cupboard > Top Shelf). Every move is logged with a timestamp, so you can always trace an object's history. Search with "where is the cable for my monitor" and get a ranked match even if you registered it as "USB-C Cable."
Timeline — every memory and every object move, merged into one chronological ledger, grouped by month.
AI Insights — a one-click summary of patterns across everything you've filed (most common category, activity volume, etc.), generated by Claude from your actual data.
Voice search — tap the mic next to either search bar and speak your query instead of typing (uses the browser's built-in speech recognition; the mic button hides itself automatically in browsers that don't support it, e.g. Firefox).
Voice dictation for filing — tap the mic next to "File entry" and speak the memory instead of typing it; ⌘/Ctrl + Enter also files the entry from the keyboard without touching the mouse.
Camera scan — in Assets, tap "Scan a shelf or wardrobe" to open your camera, point it at a shelf/drawer/wardrobe, and capture a photo. Claude's vision looks at the photo and (a) tells you if whatever you searched for is visible in frame, and (b) lists every object it can identify with a one-tap "add to inventory" checklist, so you can register a whole shelf in one photo instead of typing each item.
Full CRUD, not just create — every memory and object can be edited or deleted, not only added. Edits to a memory re-run it through AI classification so category/tags stay accurate.
Search result caching — an LRU-style in-memory cache keyed by query text avoids re-hitting the API for a repeated search, and is invalidated automatically the moment underlying data changes.
Data portability — export the whole vault as a JSON file, or import one back in (with a confirmation step and basic shape validation before overwriting anything).
Category distribution chart — a lightweight bar chart in Insights showing how your memories break down by category, computed client-side with no extra API call.
Offline detection — a banner appears automatically when the browser goes offline, since AI features need connectivity.
Keyboard-first touches — / focuses the relevant search bar from anywhere, ⌘/Ctrl + Enter files an entry.


Why it's structured this way

This is built as a personal AI OS surface, not a single-feature app — the three modules (Vault, Tracker, Timeline) share one data model and one search paradigm, which is the actual product idea worth pointing to in an interview: memory and physical inventory are the same underlying problem ("where did I put X", whether X is a thought or a passport) solved with one semantic search layer instead of two different apps.

Tech stack


Vanilla HTML/CSS/JS — no framework dependency, so it's trivial to read, deploy, or port into React/Next.js later
Anthropic Claude API (claude-sonnet-4-6) for five AI capabilities: auto-classification, semantic search, pattern insights, and image-based object detection (Claude's vision input), each constrained to strict JSON output for reliable parsing
Web Speech API (SpeechRecognition) for voice-driven search, with feature detection and graceful degradation
MediaDevices / getUserMedia for in-browser camera capture, feeding compressed JPEG frames to Claude's vision endpoint
Client-side persistent storage (key-value) standing in for a real backend/database in this prototype
Custom design system: dark "archive ledger" visual identity (catalog stamps, ledger dividers, monospace catalog numbers) built from scratch rather than a template
